# SunCart

## 📌 Project Name

**SunCart**

## 📖 Description

SunCart is an web app where people can buy their comfortable products to ease the challenges of hot summer.

## 🚀 Technologies Used

- React
- Next.js
- Tailwind CSS
- DaisyUI
- React Sprint
- React Swiper
- Better Auth
- MongoDB

## ✨ Features

1. Users can register and login.

2. Protected routes only for valid users

3. Login with Google

---

## 📌 Note

**NB:** This project has no backend. It was built for practicing React and Next.js.
